## 5. Package it

**Format: Multi-part (legacy shading).** 7 baseColor images across fuselage, wings, engines, gear and details — each a separate PBR material, so a partial repaint shows up as a patchwork.

### Option A - explicit list (copy and run)

```bash
python tools/build_slip_package.py \
  --platform android \
  --aircraft-repo infiniteflight-aircraft-a10 \
  --livery-dir "<a directory from the table above>" \
  --texture "engine_tail_lh.webp=art/engine_tail_lh.png" \
  --texture "engine_tail_rh.webp=art/engine_tail_rh.png" \
  --texture "fuselage_back.webp=art/fuselage_back.png" \
  --texture "fuselage_front.webp=art/fuselage_front.png" \
  --texture "gears.webp=art/gears.png" \
  --texture "wing_lh.webp=art/wing_lh.png" \
  --texture "wing_rh.webp=art/wing_rh.png" \
  --out out/a10.zip
```

### Option B - auto mode

```bash
python tools/build_slip_package.py --auto --art art/ \
  --platform android \
  --aircraft-repo infiniteflight-aircraft-a10 \
  --livery-dir "<a directory from the table above>" \
  --out out/a10.zip
```

`--auto` reads `data/livery_files.json`, then looks for these stems in `art/`
(`.png`, `.webp`, `.jpg` are all accepted):

```
engine_tail_lh.png
engine_tail_rh.png
fuselage_back.png
fuselage_front.png
gears.png
wing_lh.png
wing_rh.png
```

### Where the entries land

```
android: ../../files/aircraft/infiniteflight-aircraft-a10/liveries/<directory>/<file>.webp
ios:     ../../Library/dlc/aircraft/infiniteflight-aircraft-a10/liveries/<directory>/<file>.webp
```

`<directory>` must come from the table in section 4 - the folder name, not the name the app
shows.

### How to tell it worked

Each listed file is its own material, so the repaint is all-or-nothing per part: a wing still in
official colours means `wing_*.webp` did not land, a dark hull means the `_ORM` partner is missing.

## 6. Import

```bash
adb push out/a10.zip /sdcard/Download/a10.zip
adb shell "pm trim-caches <bytes>"   # only when repainting the same directory again
```

Then: **Scenery Editor → open an airport → Satellite → Import Imagery** → pick the zip,
force-stop the app, reopen. Full walkthrough: [build-and-import.md](../build-and-import.md).
