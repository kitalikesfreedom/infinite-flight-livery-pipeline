## 5. Package it

```bash
python tools/build_slip_package.py \
  --platform android \
  --aircraft-repo infiniteflight-aircraft-f18 \
  --livery-dir "<livery directory>" \
  --texture "Texture_01.webp=art/Texture_01.png" \
  --texture "Texture_02.webp=art/Texture_02.png" \
  --texture "Texture_03.webp=art/Texture_03.png" \
  --texture "Texture_04.webp=art/Texture_04.png" \
  --texture "Texture_05.webp=art/Texture_05.png" \
  # ship these unchanged (a solid fill also works) \
  --texture "Texture_01_E.webp=art/Texture_01_E.png" \
  --texture "Texture_01_ORM.webp=art/Texture_01_ORM.png" \
  --texture "Texture_02_E.webp=art/Texture_02_E.png" \
  --texture "Texture_02_ORM.webp=art/Texture_02_ORM.png" \
  --texture "Texture_03_E.webp=art/Texture_03_E.png" \
  --texture "Texture_03_ORM.webp=art/Texture_03_ORM.png" \
  --texture "Texture_04_ORM.webp=art/Texture_04_ORM.png" \
  --texture "Texture_05_ORM.webp=art/Texture_05_ORM.png" \
  --out out/f18.zip
```

Resolves to, on Android:

```
../../files/aircraft/infiniteflight-aircraft-f18/liveries/<livery directory>/<file name>
```

On iOS the root differs — replace `files` with `Library/dlc`:

```
../../Library/dlc/aircraft/infiniteflight-aircraft-f18/liveries/<livery directory>/<file name>
```

## 6. Import

```bash
adb push out/f18.zip /sdcard/Download/f18.zip
adb shell "pm trim-caches <bytes>"   # only when repainting the same directory again
```

Then: **Scenery Editor → open an airport → Satellite → Import Imagery** → pick the zip,
force-stop the app, reopen. Full walkthrough: [build-and-import.md](../build-and-import.md).
