## 5. Package it

```bash
python tools/build_slip_package.py \
  --platform android \
  --aircraft-repo infiniteflight-aircraft-c130j30 \
  --livery-dir "<livery directory>" \
  --texture "adtex.webp=art/adtex.png" \
  --texture "fuselage.webp=art/fuselage.png" \
  --texture "tail.webp=art/tail.png" \
  --texture "wings.webp=art/wings.png" \
  # ship these unchanged (a solid fill also works) \
  --texture "adtex_E.webp=art/adtex_E.png" \
  --out out/c130j30.zip
```

Resolves to, on Android:

```
../../files/aircraft/infiniteflight-aircraft-c130j30/liveries/<livery directory>/<file name>
```

On iOS the root differs — replace `files` with `Library/dlc`:

```
../../Library/dlc/aircraft/infiniteflight-aircraft-c130j30/liveries/<livery directory>/<file name>
```

## 6. Import

```bash
adb push out/c130j30.zip /sdcard/Download/c130j30.zip
adb shell "pm trim-caches <bytes>"   # only when repainting the same directory again
```

Then: **Scenery Editor → open an airport → Satellite → Import Imagery** → pick the zip,
force-stop the app, reopen. Full walkthrough: [build-and-import.md](../build-and-import.md).
