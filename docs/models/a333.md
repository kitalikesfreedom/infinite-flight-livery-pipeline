## 5. Package it

```bash
python tools/build_slip_package.py \
  --platform android \
  --aircraft-repo infiniteflight-aircraft-a333 \
  --livery-dir "<livery directory>" \
  --texture "Texture_10.webp=art/Texture_10.png" \
  --texture "Texture_11.webp=art/Texture_11.png" \
  --texture "Texture_12.webp=art/Texture_12.png" \
  --texture "Texture_13.webp=art/Texture_13.png" \
  --texture "Texture_15.webp=art/Texture_15.png" \
  --texture "Texture_16.webp=art/Texture_16.png" \
  --texture "Texture_22.webp=art/Texture_22.png" \
  # ship these unchanged (a solid fill also works) \
  --texture "Texture_10_ORM.webp=art/Texture_10_ORM.png" \
  --texture "Texture_11_ORM.webp=art/Texture_11_ORM.png" \
  --texture "Texture_12_ORM.webp=art/Texture_12_ORM.png" \
  --texture "Texture_13_ORM.webp=art/Texture_13_ORM.png" \
  --texture "Texture_15_ORM.webp=art/Texture_15_ORM.png" \
  --texture "Texture_16_ORM.webp=art/Texture_16_ORM.png" \
  --texture "Texture_22_ORM.webp=art/Texture_22_ORM.png" \
  --out out/a333.zip
```

Resolves to, on Android:

```
../../files/aircraft/infiniteflight-aircraft-a333/liveries/<livery directory>/<file name>
```

On iOS the root differs — replace `files` with `Library/dlc`:

```
../../Library/dlc/aircraft/infiniteflight-aircraft-a333/liveries/<livery directory>/<file name>
```

## 6. Import

```bash
adb push out/a333.zip /sdcard/Download/a333.zip
adb shell "pm trim-caches <bytes>"   # only when repainting the same directory again
```

Then: **Scenery Editor → open an airport → Satellite → Import Imagery** → pick the zip,
force-stop the app, reopen. Full walkthrough: [build-and-import.md](../build-and-import.md).
