## 5. Package it

```bash
python tools/build_slip_package.py \
  --platform android \
  --aircraft-repo infiniteflight-aircraft-c208 \
  --livery-dir "<livery directory>" \
  --texture "Cessna208.webp=art/Cessna208.png" \
  --texture "Texture_08.webp=art/Texture_08.png" \
  --texture "Texture_09.webp=art/Texture_09.png" \
  # ship these unchanged (a solid fill also works) \
  --texture "Texture_08_N.webp=art/Texture_08_N.png" \
  --texture "Texture_08_ORM.webp=art/Texture_08_ORM.png" \
  --out out/c208.zip
```

Resolves to, on Android:

```
../../files/aircraft/infiniteflight-aircraft-c208/liveries/<livery directory>/<file name>
```

On iOS the root differs — replace `files` with `Library/dlc`:

```
../../Library/dlc/aircraft/infiniteflight-aircraft-c208/liveries/<livery directory>/<file name>
```

## 6. Import

```bash
adb push out/c208.zip /sdcard/Download/c208.zip
adb shell "pm trim-caches <bytes>"   # only when repainting the same directory again
```

Then: **Scenery Editor → open an airport → Satellite → Import Imagery** → pick the zip,
force-stop the app, reopen. Full walkthrough: [build-and-import.md](../build-and-import.md).
