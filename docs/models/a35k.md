## 5. Package it

```bash
python tools/build_slip_package.py \
  --platform android \
  --aircraft-repo infiniteflight-aircraft-a35k \
  --livery-dir "<livery directory>" \
  --texture "A35k.webp=art/A35k.png" \
  --texture "belly.webp=art/belly.png" \
  --texture "eng.webp=art/eng.png" \
  --texture "fuse.webp=art/fuse.png" \
  --texture "gear.webp=art/gear.png" \
  --texture "wilh.webp=art/wilh.png" \
  --texture "wirh.webp=art/wirh.png" \
  # ship these unchanged (a solid fill also works) \
  --texture "belly_ORM.webp=art/belly_ORM.png" \
  --texture "eng_ORM.webp=art/eng_ORM.png" \
  --texture "fuse_ORM.webp=art/fuse_ORM.png" \
  --out out/a35k.zip
```

Resolves to, on Android:

```
../../files/aircraft/infiniteflight-aircraft-a35k/liveries/<livery directory>/<file name>
```

On iOS the root differs — replace `files` with `Library/dlc`:

```
../../Library/dlc/aircraft/infiniteflight-aircraft-a35k/liveries/<livery directory>/<file name>
```

## 6. Import

```bash
adb push out/a35k.zip /sdcard/Download/a35k.zip
adb shell "pm trim-caches <bytes>"   # only when repainting the same directory again
```

Then: **Scenery Editor → open an airport → Satellite → Import Imagery** → pick the zip,
force-stop the app, reopen. Full walkthrough: [build-and-import.md](../build-and-import.md).
