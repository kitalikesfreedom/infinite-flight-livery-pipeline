## 5. Package it

```bash
python tools/build_slip_package.py \
  --platform android \
  --aircraft-repo infiniteflight-aircraft-f16 \
  --livery-dir "<livery directory>" \
  --texture "F16C_02.webp=art/F16C_02.png" \
  --texture "F16C_Equipment.webp=art/F16C_Equipment.png" \
  --texture "F16C_01.webp=art/F16C_01.png" \
  # ship these unchanged (a solid fill also works) \
  --texture "F16C_02_ORM.webp=art/F16C_02_ORM.png" \
  --texture "F16C_01_N.webp=art/F16C_01_N.png" \
  --texture "F16C_Glass_ORM.webp=art/F16C_Glass_ORM.png" \
  --texture "F16C_01_ORM.webp=art/F16C_01_ORM.png" \
  --texture "F16C_Equipment_N.webp=art/F16C_Equipment_N.png" \
  --texture "F16C_Glass.webp=art/F16C_Glass.png" \
  --texture "F16C_02_N.webp=art/F16C_02_N.png" \
  --texture "F16C_Equipment_ORM.webp=art/F16C_Equipment_ORM.png" \
  --texture "Shadow.webp=art/Shadow.png" \
  --out out/f16.zip
```

Resolves to, on Android:

```
../../files/aircraft/infiniteflight-aircraft-f16/liveries/<livery directory>/<file name>
```

On iOS the root differs — replace `files` with `Library/dlc`:

```
../../Library/dlc/aircraft/infiniteflight-aircraft-f16/liveries/<livery directory>/<file name>
```

## 6. Import

```bash
adb push out/f16.zip /sdcard/Download/f16.zip
adb shell "pm trim-caches <bytes>"   # only when repainting the same directory again
```

Then: **Scenery Editor → open an airport → Satellite → Import Imagery** → pick the zip,
force-stop the app, reopen. Full walkthrough: [build-and-import.md](../build-and-import.md).
