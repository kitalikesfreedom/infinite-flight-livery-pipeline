### Option C - reuse the companions from an official package

The `keep` rows above are not artwork: they are masks the vendor ships. Rather than
recreating them, pull them out of an official livery package:

```bash
python tools/fetch_catalog.py --download --type AircraftLivery \
  --match a21n --out dl/
python tools/build_slip_package.py \
  --platform android \
  --aircraft-repo infiniteflight-aircraft-a21n \
  --livery-dir "<a directory from the table above>" \
  --texture "M_Fuselage_01_albd.webp=art/M_Fuselage_01_albd.png" \
  --texture "M_Fuselage_02_albd.webp=art/M_Fuselage_02_albd.png" \
  --texture "M_Fuselage_03_albd.webp=art/M_Fuselage_03_albd.png" \
  --texture "M_LandingGear_02_albd.webp=art/M_LandingGear_02_albd.png" \
  --texture "M_PW1100G_Left_albd.webp=art/M_PW1100G_Left_albd.png" \
  --texture "M_PW1100G_Right_albd.webp=art/M_PW1100G_Right_albd.png" \
  --texture "M_Wings_01_albd.webp=art/M_Wings_01_albd.png" \
  --texture "M_Wings_02_albd.webp=art/M_Wings_02_albd.png" \
  --keep-from dl/<downloaded package>.zip \
  --out out/a21n.zip
```

`--keep-from` copies every entry in that archive **except** the albedo files, so your own
artwork always wins and the companions stay byte-identical to the vendor's.

### Where the entries land

```
android: ../../files/aircraft/infiniteflight-aircraft-a21n/liveries/<directory>/<file>.webp
ios:     ../../Library/dlc/aircraft/infiniteflight-aircraft-a21n/liveries/<directory>/<file>.webp
```

`<directory>` must come from the table in section 4 - the folder name, not the name the app
shows.

### How to tell it worked

Every part is a separate material: a correct repaint shows **all** listed albedo files changed.
One part still in official colours means that `M_*_albd.webp` entry is missing from the archive.
Do not touch the `_comp` files - they carry the metallic/roughness mask and are what stop the
fuselage from turning into a mirror.

## 6. Import

```bash
adb push out/a21n.zip /sdcard/Download/a21n.zip
adb shell "pm trim-caches <bytes>"   # only when repainting the same directory again
```

Then: **Scenery Editor → open an airport → Satellite → Import Imagery** → pick the zip,
force-stop the app, reopen. Full walkthrough: [build-and-import.md](../build-and-import.md).
