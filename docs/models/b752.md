## 5. Package it

```bash
python tools/build_slip_package.py \
  --platform android \
  --aircraft-repo infiniteflight-aircraft-b752 \
  --livery-dir "<livery directory>" \
  --texture "b757_back.webp=art/b757_back.png" \
  --texture "b757_front.webp=art/b757_front.png" \
  --texture "b757_gear.webp=art/b757_gear.png" \
  --texture "b757_RB211.webp=art/b757_RB211.png" \
  --texture "b757_tail.webp=art/b757_tail.png" \
  --texture "b757_wingL.webp=art/b757_wingL.png" \
  --texture "b757_wingR.webp=art/b757_wingR.png" \
  # ship these unchanged (a solid fill also works) \
  --texture "b757_back_ORM.webp=art/b757_back_ORM.png" \
  --texture "b757_front_ORM.webp=art/b757_front_ORM.png" \
  --texture "b757_RB211_ORM.webp=art/b757_RB211_ORM.png" \
  --texture "b757_tail_ORM.webp=art/b757_tail_ORM.png" \
  --texture "b757_wingL_ORM.webp=art/b757_wingL_ORM.png" \
  --texture "b757_wingR_ORM.webp=art/b757_wingR_ORM.png" \
  --out out/b752.zip
```

Resolves to, on Android:

```
../../files/aircraft/infiniteflight-aircraft-b752/liveries/<livery directory>/<file name>
```

On iOS the root differs — replace `files` with `Library/dlc`:

```
../../Library/dlc/aircraft/infiniteflight-aircraft-b752/liveries/<livery directory>/<file name>
```

## 6. Import

```bash
adb push out/b752.zip /sdcard/Download/b752.zip
adb shell "pm trim-caches <bytes>"   # only when repainting the same directory again
```

Then: **Scenery Editor → open an airport → Satellite → Import Imagery** → pick the zip,
force-stop the app, reopen. Full walkthrough: [build-and-import.md](../build-and-import.md).
