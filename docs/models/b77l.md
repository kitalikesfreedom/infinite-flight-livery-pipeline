## 5. Package it

```bash
python tools/build_slip_package.py \
  --platform android \
  --aircraft-repo infiniteflight-aircraft-b77l \
  --livery-dir "<livery directory>" \
  --texture "b777_200er_ge90_115b.webp=art/b777_200er_ge90_115b.png" \
  --texture "b777_200er_uv1.webp=art/b777_200er_uv1.png" \
  --texture "b777_200er_uv2.webp=art/b777_200er_uv2.png" \
  --texture "b777_200er_uv3.webp=art/b777_200er_uv3.png" \
  --texture "b777_200er_uv4.webp=art/b777_200er_uv4.png" \
  --texture "b777_200er_uv5.webp=art/b777_200er_uv5.png" \
  --texture "b777_200er_uv6.webp=art/b777_200er_uv6.png" \
  --texture "b777_200er_uv7.webp=art/b777_200er_uv7.png" \
  --texture "b777_200er_uv8.webp=art/b777_200er_uv8.png" \
  --texture "b777_200er_uv9.webp=art/b777_200er_uv9.png" \
  # ship these unchanged (a solid fill also works) \
  --texture "Texture.webp=art/Texture.png" \
  --out out/b77l.zip
```

Resolves to, on Android:

```
../../files/aircraft/infiniteflight-aircraft-b77l/liveries/<livery directory>/<file name>
```

On iOS the root differs — replace `files` with `Library/dlc`:

```
../../Library/dlc/aircraft/infiniteflight-aircraft-b77l/liveries/<livery directory>/<file name>
```

## 6. Import

```bash
adb push out/b77l.zip /sdcard/Download/b77l.zip
adb shell "pm trim-caches <bytes>"   # only when repainting the same directory again
```

Then: **Scenery Editor → open an airport → Satellite → Import Imagery** → pick the zip,
force-stop the app, reopen. Full walkthrough: [build-and-import.md](../build-and-import.md).
