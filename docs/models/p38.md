## 5. Package it

```bash
python tools/build_slip_package.py \
  --platform android \
  --aircraft-repo infiniteflight-aircraft-p38 \
  --livery-dir "<livery directory>" \
  --texture "P38G_01.webp=art/P38G_01.png" \
  --texture "P38G_02.webp=art/P38G_02.png" \
  --texture "P38G_Fan.webp=art/P38G_Fan.png" \
  --texture "P38G_Tank.webp=art/P38G_Tank.png" \
  # ship these unchanged (a solid fill also works) \
  --texture "P38-tank.webp=art/P38-tank.png" \
  --texture "P38F-01.webp=art/P38F-01.png" \
  --texture "P38F-02.webp=art/P38F-02.png" \
  --texture "P38G_01_N.webp=art/P38G_01_N.png" \
  --texture "P38G_01_ORM.webp=art/P38G_01_ORM.png" \
  --texture "P38G_02_N.webp=art/P38G_02_N.png" \
  --texture "P38G_02_ORM.webp=art/P38G_02_ORM.png" \
  --texture "P38G_Fan_ORM.webp=art/P38G_Fan_ORM.png" \
  --texture "P38G_Glass.webp=art/P38G_Glass.png" \
  --texture "P38G_Glass_ORM.webp=art/P38G_Glass_ORM.png" \
  --texture "P38G_Tank_N.webp=art/P38G_Tank_N.png" \
  --texture "P38G_Tank_ORM.webp=art/P38G_Tank_ORM.png" \
  --texture "Propeller.webp=art/Propeller.png" \
  --out out/p38.zip
```

Resolves to, on Android:

```
../../files/aircraft/infiniteflight-aircraft-p38/liveries/<livery directory>/<file name>
```

On iOS the root differs — replace `files` with `Library/dlc`:

```
../../Library/dlc/aircraft/infiniteflight-aircraft-p38/liveries/<livery directory>/<file name>
```

## 6. Import

```bash
adb push out/p38.zip /sdcard/Download/p38.zip
adb shell "pm trim-caches <bytes>"   # only when repainting the same directory again
```

Then: **Scenery Editor → open an airport → Satellite → Import Imagery** → pick the zip,
force-stop the app, reopen. Full walkthrough: [build-and-import.md](../build-and-import.md).
