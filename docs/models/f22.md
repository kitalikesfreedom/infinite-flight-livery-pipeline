## 5. Package it

```bash
python tools/build_slip_package.py \
  --platform android \
  --aircraft-repo infiniteflight-aircraft-f22 \
  --livery-dir "<livery directory>" \
  --texture "base.webp=art/base.png" \
  # ship these unchanged (a solid fill also works) \
  --texture "glass.webp=art/glass.png" \
  --texture "Cockpit_ORM.webp=art/Cockpit_ORM.png" \
  --texture "glass_N.webp=art/glass_N.png" \
  --texture "base_ORM.webp=art/base_ORM.png" \
  --texture "Cockpit.webp=art/Cockpit.png" \
  --texture "base_N.webp=art/base_N.png" \
  --texture "glass_ORM.webp=art/glass_ORM.png" \
  --texture "Cockpit_E.webp=art/Cockpit_E.png" \
  --texture "Shadow.webp=art/Shadow.png" \
  --out out/f22.zip
```

Resolves to, on Android:

```
../../files/aircraft/infiniteflight-aircraft-f22/liveries/<livery directory>/<file name>
```

On iOS the root differs — replace `files` with `Library/dlc`:

```
../../Library/dlc/aircraft/infiniteflight-aircraft-f22/liveries/<livery directory>/<file name>
```

## 6. Import

```bash
adb push out/f22.zip /sdcard/Download/f22.zip
adb shell "pm trim-caches <bytes>"   # only when repainting the same directory again
```

Then: **Scenery Editor → open an airport → Satellite → Import Imagery** → pick the zip,
force-stop the app, reopen. Full walkthrough: [build-and-import.md](../build-and-import.md).
